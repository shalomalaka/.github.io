N-back cognitive assessment

SYSC 2010 · Python + Lithic One motion sensor

Answer memory prompts with arm motions instead of buttons. The test adapts its difficulty as you go.

Under the hood: the source code

Written in Python (backtest.py), the program ties the sensor, the prompts and the scoring into one test session:

  • Sensor input: the Lithic library streams accelerometer and gyroscope data from the Lithic One, and the code decides which arm motion you made.
  • Prompts: colour and tone sequences, with audio handled in Python through pygame.
  • Live GUI: a tkinter progress window shows the test number, current N-back level, score and sequence progress as you go.
  • Session setup: each run starts by recording the patient’s and tester’s names, the way a clinical assessment would.
  • Adaptive logic: the N-back level rises or falls based on how you’re scoring.
